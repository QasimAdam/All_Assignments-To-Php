## ▶️ How to Run the PHP Files

PHP files cannot normally be opened by simply double-clicking them like a normal HTML file.

You need a PHP server such as:

* XAMPP
* Laragon
* WAMP
* PHP built-in development server

### Using PHP Built-in Server

Open PowerShell or Command Prompt inside the project folder:

```bash
cd "Chapter2 practice"
```

Then run:

```bash
php -S localhost:8000
```

You should see a message similar to:

```text
PHP Development Server started
```

Open your browser and visit:

```text
http://localhost:8000
```

Then select the PHP file you want to practice.

## 💡 Practice Method

For each PHP file:

1. Open the `.php` file.
2. Read the code carefully.
3. Understand what each line does.
4. Run the file using a PHP server.
5. Check the browser output.

7. Run it again.
8. Compare the new output with the original output.
