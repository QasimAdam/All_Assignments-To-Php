## RUN

Place the folder inside your XAMPP `htdocs` folder.

Example:

```text
C:\xampp\htdocs\Chapter3 practice
```

Start **Apache** from XAMPP Control Panel.

Then open the project in your browser:

```text
http://localhost/Chapter3%20practice/
```

To run a specific file:

```text
http://localhost/Chapter3%20practice/01_Numerically_Indexed_Arrays.php
```

For files **26-29**, keep `library.php` in the same folder.

## PRACTICE

For each PHP file:

1. Open the PHP file.
2. Read the comments and code.
3. Run the file using XAMPP.
4. Check the output in the browser.
5. Change the values and test the code again.
6. Practice writing the example yourself.

## CHAPTER TOPICS

This chapter focuses on two main PHP topics:

### Arrays

Arrays allow multiple values to be stored under one variable.

Main types covered:

* Numerically Indexed Arrays
* Associative Arrays
* Multidimensional Arrays

### Functions

Functions allow reusable blocks of code to be created and called when needed.

Main concepts covered:

* Function Definition
* Function Call
* Parameters
* Arguments
* Return Values
* Passing By Value
* Passing By Reference
* Default Arguments
* Variable Scope
* Including PHP Files
